References & Contact#

Citing PyDMD#

When using PyDMD in your work, please cite both of the following:

  • Demo, Tezzele, Rozza. PyDMD: Python Dynamic Mode Decomposition. Journal of Open Source Software, 2018. DOI

  • Ichinaga, Andreuzzi, Demo, Tezzele, Lapo, Rozza, Brunton, Kutz. PyDMD: A Python Package for Robust Dynamic Mode Decomposition. Journal of Machine Learning Research, 2024. DOI arXiv

References#

General DMD References#

  • Kutz, Brunton, Brunton, Proctor. Dynamic Mode Decomposition: Data-Driven Modeling of Complex Systems. SIAM, 2016.

  • Schmid. Dynamic mode decomposition of numerical and experimental data. Journal of Fluid Mechanics, 2010.

  • Tu, Rowley, Luchtenburg, Brunton, Kutz. On Dynamic Mode Decomposition: Theory and Applications. Journal of Computational Dynamics, 2014.

  • Schmid. Dynamic mode decomposition and its variants. Annual Review of Fluid Mechanics, 2022.

  • Hemati, Rowley, Deem, Cattafesta. De-biasing the dynamic mode decomposition. Theoretical and Computational Fluid Dynamics, 2017.

  • Héas, Herzet. Low-rank dynamic mode decomposition. Journal of Nonlinear Science, 2022.

  • Takeishi, Kawahara, Yairi. Subspace dynamic mode decomposition. Physical Review E, 2017.

  • Baddoo, Herrmann, McKeon, Kutz, Brunton. Physics-informed dynamic mode decomposition. Proceedings of the Royal Society A, 2023.

  • Askham, Kutz. Variable projection methods for an optimized dynamic mode decomposition. SIAM Journal on Applied Dynamical Systems, 2018.

  • Sashidhar, Kutz. Bagging, optimized dynamic mode decomposition. Proceedings of the Royal Society A, 2022.
